# Resource submission guidelines

A strong submission links to the canonical project, identifies its actual type, uses a neutral one-sentence description, supplies documented compatibility, and explains why it is distinct from existing entries. Prefer an individual skill or server page over a parent collection when a stable direct link exists.

Self-submissions are welcome when disclosed. Inclusion is editorial and may be declined for weak documentation, inactivity, duplication, unclear licensing, unsafe installation behavior, or limited usefulness.
