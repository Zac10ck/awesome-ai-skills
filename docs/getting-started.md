# Getting started

Start with the resource type: an Agent Skill supplies instructions, an MCP server exposes tools or data, a framework helps build applications, and a guide provides reference material. These are not interchangeable.

Before installing anything, read the source, license, recent activity, issue tracker, requested permissions, network access, and setup commands. Test third-party tools with minimal privileges and non-sensitive data. Follow the linked project's own documentation because this directory does not mirror installation instructions.
