# MCP essentials

A focused path through the Model Context Protocol ecosystem. MCP servers can receive credentials, call external services, and access local data, so review source code and scope permissions before connecting one.

## Learn and build

| Resource | Purpose |
|---|---|
| [Model Context Protocol documentation](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro) | Protocol concepts, architecture, and current documentation. |
| [MCP Reference Servers](https://github.com/modelcontextprotocol/servers) | Educational server implementations maintained by the MCP project. |
| [MCP Inspector](https://github.com/modelcontextprotocol/inspector) | Interactive testing and debugging for MCP servers. |
| [Python SDK](https://github.com/modelcontextprotocol/python-sdk) | Build Python MCP clients and servers. |
| [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) | Build TypeScript MCP clients and servers. |

## Useful servers

- [GitHub MCP Server](https://github.com/github/github-mcp-server) — repositories, issues, pull requests, and workflows.
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) — browser automation using structured page data.
- [Context7](https://github.com/upstash/context7) — version-aware library documentation.
- [Firecrawl MCP](https://github.com/mendableai/firecrawl-mcp-server) — web search, crawling, and extraction.
- [Sentry MCP](https://github.com/getsentry/sentry-mcp) — application errors and observability data.
- [Notion MCP](https://github.com/makenotion/notion-mcp-server) — pages, databases, and workspace knowledge.
- [Supabase MCP](https://github.com/supabase-community/supabase-mcp) — database and project workflows.

See [How to use MCP safely](../docs/how-to-use-mcp.md) before installation.
