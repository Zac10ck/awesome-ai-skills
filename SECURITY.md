# Security Policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability in this repository's scripts or automation. Use GitHub's private vulnerability reporting feature when available, or contact the repository owner privately through the contact method on their GitHub profile.

Include affected files, impact, reproduction steps, and any suggested mitigation. Please allow a reasonable period for triage before public disclosure.

## Third-party resources

This repository indexes external projects; it does not audit or guarantee them. Report vulnerabilities in linked projects to their maintainers. If a listed resource appears compromised, malicious, or misleading, use the broken-link issue form and mark the concern as security-related without publishing exploit details.
